# Документы проекта

Описание проекта собрано по файлам Markdown репозитория.

* [README](../README.md): запуск, состояние и ограничения.
* [Путеводитель по документации](guide/README.md): все разделы сервиса.
* [Описание модели](ml-заново/README.md): обучение, калибровка и запуск.
* [Оформление интерфейса](frontend/REFERENCE_DESIGN.md): визуальные решения и шрифты.

Рабочие документы команды (план работ, статус передачи, список оставшихся задач и матрица требований) ведутся в ветке `develop` и в поставку не входят.
