# Что умеет приложение

В текущей версии есть:

* вход и рабочие места для пяти ролей;
* объекты, каналы датчиков и журнал событий;
* импорт журнала с русскими названиями полей;
* карта, список прогнозов и карточка выбранного объекта;
* сохранение решения с причиной и комментарием;
* рекомендации по обслуживанию и комментарии к работам;
* аналитические экраны и журнал действий;
* расчёт прогноза новой тревоги с помощью CatBoost;
* отдельные режимы правил и тестовой заглушки.

Для локального запуска используется SQLite. Для PostgreSQL подготовлены схема и миграции.

### Роли

| Роль | Основные действия |
| --- | --- |
| Диспетчер, `dispatcher` | Смотрит карту и сигналы, проверяет прогноз, сохраняет решение. |
| Техник, `technician` | Открывает рекомендации и схему проверки, добавляет комментарии к работам. |
| Руководитель, `manager` | Смотрит состояние участков, решения и работы. |
| Аналитик, `analyst` | Работает с данными и качеством прогнозов, сохраняет паспорт канала и запускает расчёт. |
| Администратор, `admin` | Работает с настройками, порогами и журналом действий. |

### Карта и уведомления

На карте можно выбрать объект и открыть связанный прогноз. Тоннели, координаты и камеры в демонстрации условные. Видео с камер не передаётся.

В приложении есть очередь сигналов и внутренние уведомления. Telegram-доставка по умолчанию выключена. SMS и email сохраняются локально без отправки. Подробности в [основном README](../../README.md#telegram-уведомления).
