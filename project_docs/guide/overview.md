# О проекте

Сервис Москоллектор помогает диспетчеру следить за состоянием инженерных коллекторов. В одном приложении собраны события датчиков, карта, прогнозы, рекомендации по обслуживанию и история решений.

Диспетчер видит сигнал, открывает показания, изучает прогноз и выбирает действие. Причина и комментарий сохраняются в журнале. Решение принимает сотрудник. Приложение не управляет оборудованием и не отправляет бригаду автоматически.

Сервис предназначен для наблюдения за изменениями показаний, выбора объектов для осмотра и разбора повторяющихся тревог. Данных об экономии средств и сокращении числа выездов пока нет.

В репозитории собраны сервер, интерфейс и модель, которая оценивает вероятность новой тревожной записи по каналу датчика в следующие 24 часа. Отдельно доступны прогнозы по правилам. Демонстрационные данные позволяют пройти путь от события до сохранённого решения.
