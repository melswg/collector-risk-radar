# Настройки

| Параметр | Для чего нужен |
| --- | --- |
| `DEMO_PASSWORD` | Пароль для создания демонстрационных пользователей и входа. |
| `ML_MODE=rules` | Расчёт по правилам для объектов. Отдельный API прогноза по каналу остаётся самостоятельным способом расчёта. |
| `ML_MODE=http` | Подключение внешнего сервиса по ранее подготовленному API. |
| `AUTH_MODE=demo` | Вход под демонстрационными пользователями. |
| `.env.example` | Пример настроек стенда. |
| `make configure` | Подготовка настроек перед запуском полного стенда. |
| YAML | Пороги, правила, сроки обслуживания и справочники. |

Переменные окружения перечислены в [.env.example](../../.env.example). Команда `make configure` создаёт локальный `.env`. Пароли и ключи хранятся вне репозитория.
