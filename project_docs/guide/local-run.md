# Локальный запуск

Нужны Python 3.11 или выше, Node.js/npm и `make`. Команды рассчитаны на оболочку Linux или macOS.

Выполняйте команды из локальной копии репозитория.

### Сервер

Из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt -r ml-заново/requirements-inference.txt
export DEMO_PASSWORD='<свой пароль длиной не менее 12 символов>'
python -m backend.seed
make local
```

Замените значение `DEMO_PASSWORD` собственным паролем. Он нужен для создания пользователей и входа. Не добавляйте пароль в репозиторий.

При локальном запуске используется SQLite. API работает по адресу `127.0.0.1:8000`.

### Интерфейс

В другом терминале:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который напечатает сервер разработки. Основная страница `/` обращается к API через Vite proxy. Для входа используйте имя роли и пароль, заданный при создании пользователей.

### Демо без сервера

На странице `/demo.html` доступны логины `dispatcher`, `technician`, `manager`, `analyst` и `admin`. Пароль для всех: `demo`.

В этом режиме данные и решения сохраняются только в браузере. Расчёт CatBoost недоступен. Для работы с сервером и моделью открывайте основную страницу `/`.
