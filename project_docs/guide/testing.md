# Запуск тестов

С активированным окружением из корня проекта:

```bash
python -m pytest -q
```

Проверки интерфейса:

```bash
cd frontend
node --test tests/*.test.mjs
npm run build
```

Для отдельного внешнего сервиса в спецификации предусмотрена команда `make test-contract ML_URL=…`. Она проверяет обмен данными и не заменяет проверку прогноза по каналу.
