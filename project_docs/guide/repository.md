# Структура проекта

Сервер, интерфейс и модель находятся в одном репозитории.

| Путь | Содержимое |
| --- | --- |
| `README.md` | Описание проекта и быстрый запуск. |
| `backend/` | Сервер, работа с данными и расчёты. |
| `backend/api.py`, `backend/services.py`, `backend/auth.py` | API, действия пользователей и роли. |
| `backend/db.py`, `backend/schema.sql`, `backend/migrations/` | База данных и миграции. |
| `backend/ingestion.py`, `backend/adapters.py`, `backend/context.py` | Приём данных, источники и подготовка данных объекта. |
| `backend/prediction_providers/` | Правила и подключение внешнего сервиса. |
| `backend/ml_channel.py` | Подключение модели прогноза по каналу. |
| `backend/scheduler.py`, `backend/worker.py` | Фоновые задачи. |
| `frontend/` | Интерфейс и его тесты. |
| `ml-заново/` | Подготовка признаков, применение модели, калибровка и веса. |
| `contracts/ml/` | Ранее подготовленное описание обмена с внешним сервисом модели. |
| `config/` | Настройки и справочники. |
| `deploy/` | Материалы для развёртывания. |
| `tools/` | Вспомогательные средства и демонстрационные сценарии. |
| `tests/` | Проверки сервера, обмена данными и модели. |
| `docs/` | Спецификация и руководство по работе с приложением. |
| `.env.example`, `Makefile` | Пример настроек и команды запуска. |

[Все разделы](README.md)
