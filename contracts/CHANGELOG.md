# Контракт ML

## 1.0 — 2026-09-19
Заморожен исходный черновик приложения C. Уточнения: kind допускает stub для честного шаблона; запрос содержит не более 50 объектов; what_if ограничен weather.forecast.precip_mm_delta; одинаковый request_id с другим содержимым даёт 409. UTC обязателен, будущие точки и публикации запрещены. Полнота декартова произведения объект × тип × горизонт проверяется клиентом, кроме объектов с errors. Контекстный объект считается известным без внешнего реестра; ML_KNOWN_OBJECTS включает строгую проверку. Версия определяется парой id/version, для активации версии допустим id@version. Недостаток данных возвращается явно без уверенной вероятности. Дальнейшие изменения — только обратно совместимо с записью здесь.
