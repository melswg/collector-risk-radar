# Передача текущей версии проекта «Контур / Москоллектор»

Дата: 19 сентября 2026 года. Это незавершённая рабочая версия, а не выполненное полностью ТЗ.
По просьбе пользователя разработка переключена на передачу файлов и инструкции по продолжению.

## Что находится в папке

- `backend/` — FastAPI, SQLAlchemy, импорт, диагностика, контекст, правила, HTTP/fallback/shadow, решения, рекомендации, метрики, выгрузки, LDAP/RBAC, планировщик/worker.
- `frontend/` — React 18 + TypeScript + Vite, Leaflet, Recharts. Исходники, установленные зависимости и собранный `dist` сохранены.
- `contracts/ml/` — JSON Schema запроса/ответа/обучения, OpenAPI v1.0. Контракт требует завершающей проверки полноты.
- `ml_service_template/` — FastAPI-шаблон со специально помеченными STUB в predictor/trainer. Настоящего ML здесь нет.
- `tools/synth/`, `tools/emulator/` — генератор и демо-сценарии.
- `data/` — локальная SQLite-база и первый синтетический набор: 12 объектов, 108 каналов, 1 год компактной истории с плотными окнами.
- `deploy/`, `Makefile`, `.env.example`, `.env` — конфигурация развёртывания. `.env` содержит сгенерированные секреты локального стенда, не публикуйте его в репозитории.
- `tests/` — начальный набор unit/API/контрактных тестов и Locust.
- `docs/ASSUMPTIONS.md` — принятые допущения.
- `docs/SPECIFICATION.md` — полный исходный текст ТЗ.
- `docs/HANDOFF_STATUS.md` — факты о текущих проверках и ограничения.
- `ЧТО_ОСТАЛОСЬ_СДЕЛАТЬ.md` — подробная последовательность продолжения.
- `ИСХОДНИКИ_ЗАДАНИЯ/` — три исходных файла пользователя.

## Быстрый локальный запуск для продолжения

Потребуются Python 3.12 и Node 22+. Команды выполнять из этой папки.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.lock.txt
set -a
source .env
set +a
export COOKIE_SECURE=false
npm --prefix frontend ci
npm --prefix frontend run build
python -m backend.seed
python -m uvicorn backend.api:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Swagger: `http://127.0.0.1:8000/docs`.
Пользователи: `dispatcher`, `analyst`, `manager`, `technician`, `admin`.
Пароль берётся из `DEMO_PASSWORD` в `.env`; все пять демо-учётных записей используют его.
Запускать seed повторно допустимо, но текущая реализация при наличии объектов пропускает повторную загрузку данных.

Если Python 3.12 не установлен, на исходном компьютере доступен:
`/Users/mark/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`.
Для ускорения можно использовать уже созданное окружение:
`/Users/mark/Documents/Codex/2026-09-19/new-chat/work/venv/bin/python`.
Это абсолютные пути данного компьютера, на другой машине создайте новое окружение.

Для разработки frontend отдельно:

```bash
npm --prefix frontend run dev
```

Vite перенаправляет `/api` на локальный backend:8000.

## Целевой Docker-запуск после исправлений

```bash
make up
make seed
```

Адрес: `https://localhost:8443`, самоподписанный TLS-сертификат.
Сначала устраните замечания к миграции и образам из инструкции продолжения.
Для ML-шаблона: `make up-ml`; для реального ML нужен сервис другого участника.
Не заменяйте реальные проверки утверждением о соответствии ТЗ.
