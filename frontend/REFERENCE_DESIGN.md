# Перенос приёмов из референсов

Источники: [Easy Commerce, Poool](https://poool.studio/ru/projects/easy-commerce) и [Иннотех, ONY](https://ony.ru/work/innotech). Изучены экраны и графика проектов внутри кейсов, не оформление сайтов агентств.

- Easy Commerce: тёмная группа пронумерованных вкладок и светлый выбранный модуль. В рабочем месте это очередь прогнозов, где выбранный участок связан с картой и инспектором. Тональный голубой переход применяется только к выбранной карточке и экрану входа.
- Иннотех: широкая плотная акцидентная типографика, левое выравнивание, тонкие разделители и ограниченная синяя палитра. В интерфейсе эти приёмы выделяют название участка, заголовки рабочих мест и числовые значения.
- Движение: короткое смещение стрелки основного действия; при reduced-motion отключается. Фоновое видео и постоянная 3D-анимация не добавлялись в рабочий экран.

В источниках названы ONY Okkam и Cofo Kak Black. Пользователь выбрал свободные аналоги: Golos Text для интерфейсных данных и Unbounded для крупных заголовков/значений. Это замены по характеру, не идентичные гарнитуры. WOFF2 с латиницей и кириллицей хранятся локально в public/fonts; рядом сохранены лицензии OFL. Источник файлов: Google Fonts CSS API и fonts.gstatic.com. Тексты лицензий: пакеты @fontsource/golos-text и @fontsource/unbounded 5.2.8.

Реализация: src/reference-system.css, подключён последним в src/main.tsx. Изменения действуют в основном приложении и demo.html. Изолированный старый map-preview не является этой новой версией.

Проверено: диспетчер 1280/375/320 px, переключение/карточка прогноза, SVG графика после отложенной загрузки; desktop-обзор руководителя. На 320/375 px ширина страницы равна viewport. Полная повторная приёмка всех ролей и состояний после этого визуального слоя ещё требуется.
