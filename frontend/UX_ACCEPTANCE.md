# Приёмка UX/UI

Область: frontend в проверенном кодовом срезе `develop` `ce81e97` (29.09), светлый макет с голубой картой и синим текстом. Этот список не заменяет официальный `REQUIREMENTS_CHECKLIST.md`. Локальный API и браузер подтвердили одну синтетическую карточку настоящего каналового ML-прогноза и сохранённое решение диспетчера. Реальные камеры, данные заказчика и доставка сообщений не подключены.

## Оставшаяся приёмка frontend

- [ ] Единый проход по всем ролям на desktop и мобильной ширине после последних изменений, включая ML-карточку, длинный текст, клавиатуру, фокус модальных окон и масштаб текста 200%.
- [ ] Проверить тёмный вариант, ранее запрошенный пользователем: текущая утверждённая оболочка реализует светлое оформление; наличие старых файлов тем не подтверждает доступный переключатель.
- [ ] Проверить отказ подложки карты, загрузку/ошибки списка и карточек: пользователь должен понимать причину и способ повторить запрос.
- [ ] Проверить цепочку уведомление → помощник → прогноз с другого раздела и несколько последовательных критических сигналов.
- [ ] Сверить опубликованные frontend-файлы с локальной версией после следующих изменений. Точки входа и текущие ограничения README обновлены 29.09.

## Не выдавать за готовую интеграцию

Демонстрационные координаты не являются сетью заказчика. Имитация камеры не является видеопотоком. Действия в demo не отправляют наряды, не управляют оборудованием и не отправляют Telegram/SMS/email. Назначение бригад, полная история смен и эффективность персонала не переданы текущему frontend. Проверенный ML-прогноз использует синтетический паспорт и журнал: его качество на реальных данных этим аудитом не доказано. Полный аудит прав ролей на целевом стенде также не выполнен.
