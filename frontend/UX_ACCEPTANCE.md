# Приёмка UX/UI

Область: frontend ветки `ux-ui`, утверждённый светлый макет с голубой картой и синим текстом. Backend, ML, реальные камеры и доставка сообщений подключаются отдельно по поручению пользователя. Этот список не заменяет официальный REQUIREMENTS_CHECKLIST и не отмечает требования выполненными в develop.

## Проверено в локальном демо

## Оставшаяся приёмка frontend

- [ ] Единый проход по всем ролям на desktop и мобильной ширине после последних изменений, включая длинный текст, клавиатуру, фокус модальных окон и масштаб текста 200%.
- [ ] Проверить тёмный вариант, ранее запрошенный пользователем: текущая утверждённая оболочка реализует светлое оформление; наличие старых файлов тем не подтверждает доступный переключатель.
- [ ] Проверить отказ подложки карты, загрузку/ошибки списка и карточек: пользователь должен понимать причину и способ повторить запрос.
- [ ] Проверить цепочку уведомление → помощник → прогноз с другого раздела и несколько последовательных критических сигналов.
- [ ] Проверить соответствие README текущим точкам входа и финальным ограничениям; сверить опубликованные frontend-файлы с локальной версией.

## Не выдавать за готовую интеграцию

Демонстрационные координаты не являются сетью заказчика. Имитация камеры не является видеопотоком. Действия в demo не отправляют наряды, не управляют оборудованием и не отправляют Telegram/SMS/email. Назначение бригад, полная история смен и эффективность персонала не переданы текущему frontend. Серверные проверки прав и живая модель этим аудитом не проверены.
