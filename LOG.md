### 48. 2026-09-28 · `fix(ui): ignore stale workspace refresh responses`

- Общая загрузка рабочего места теперь принимает только результат последнего начатого запроса в текущей сессии. Медленный предыдущий запрос не возвращает старый фильтр событий и не закрывает свежие данные своей запоздалой ошибкой.
- Добавлены два регрессионных сценария с управляемым порядком завершения Promise: новый фильтр завершается раньше старого; старый таймаут приходит после успешного обновления. Оба сохраняют свежие данные. Всего 15 тестов Node, TypeScript/Vite и diff-check проходят.
- Проверки воспроизводят гонку локально, без изменения backend или сетевых запросов заказчика. Публикация новых локальных коммитов ещё не выполнена.

### 47. 2026-09-28 · `fix(ui): make notification inbox keyboard accessible`

- Список уведомлений вынесен в NotificationInbox и оформлен как диалог с подложкой. Раньше открытие оставляло фокус на колокольчике, Escape не закрывал список. Теперь фокус переходит в панель, Tab ограничен её контролами, закрытие возвращает фокус.
- При открытии прогноза повторные клики блокируются и отображается состояние загрузки. Ошибка видна в открытой панели. Если прогноз не прикреплён, строка прямо сообщает об этом; отсутствующая вероятность не превращается в NaN%.
- Проверено в браузере на 320 px: открытие → Shift+Tab на последнюю запись → Escape, возврат на «Уведомления»; уведомление о подтоплении → одна карточка прогноза с фокусом на закрытии. ### 46. 2026-09-28 · `fix(ui): queue critical alerts and isolate dialog dismissal`

- Критические прогнозы хранятся очередью: новый не заменяет уже открытый; принятие убирает только первый. Повторы одного notification id не дублируются. Выход очищает всю очередь.
- Запоздалый ответ потока проверяет поколение сессии перед изменением UI. Некорректное JSON-событие не роняет обработчик; недоступный звуковой контекст не мешает визуальному сигналу. Переключение звука не отменяет уже запрошенный прогноз той же сессии.
- Escape обрабатывается самим критическим диалогом и не закрывает инспектор карты. Обновление родителя не переносит фокус обратно на первую кнопку. При критическом окне камера закрывается, чтобы не оставалось двух модальных окон.
- Проверено: 13 тестов Node (включая очередь из двух сигналов и повтор доставки), TypeScript/Vite. В браузере: демопожар → Tab на «Принято, проверить позже» → Escape; alertdialog исчез, Пресня осталась выбранной, body overflow восстановлен. Реальный SSE-поток и смена сессии с задержанным сетевым ответом сквозной проверкой пока не подтверждены.
