# Что ещё нужно проверить

| Область | Оставшаяся работа |
| --- | --- |
| Реальные данные | Получить полный реестр каналов и рабочий журнал, проверить время и пропуски. |
| Качество модели | Проверить прогноз на реальных событиях и выбрать порог действия. |
| Повторное обучение | Получить отсутствующую исходную таблицу и воспроизвести подготовку модели. |
| Другие прогнозы | Согласовать смысл результатов и подключить остальные модели. |
| Погода и ремонт | Подключить подтверждённые источники. |
| Карта | Получить настоящие координаты и выбрать вариант подложки для рабочего использования. |
| Внешние сообщения | Реализовать и проверить доставку Telegram, SMS или email. |
| Сервер | Проверить PostgreSQL, Redis, Docker, сбои и восстановление. |
| Доступ | Проверить LDAP/AD, TLS и права всех ролей. |
| Нагрузка | Измерить задержки при одновременной работе пользователей. |
| Интерфейс | Пройти все роли, мобильные размеры, управление клавиатурой, масштаб текста 200% и ошибки сети. |

Текущий час может быть заполнен не полностью. Это отличается от полной часовой записи, использованной при обучении, и требует отдельной проверки.

При подключении к заказчику внешние системы должны использоваться только для чтения. Данные должны поступать обезличенными. Соответствие нормативным требованиям и условиям лицензий требует отдельной проверки перед внедрением.
