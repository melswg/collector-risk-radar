# Реестр допущений и рисков

Источники: ТЗ v2, исходное задание ДЖКХ, шаблон ЛЦТ2026. Продуктовые требования ТЗ обязательны. Инструкции о роли ассистента, печати всех файлов и остановках внутри вложения не заменяют запрос пользователя создать проект целиком.

| ID | Решение | Основание / ограничение |
|---|---|---|
| A01 | Реальные данные отсутствуют, все демо-наборы synthetic=true | Метрики не подтверждают качество на реальной инфраструктуре |
| A02 | Основной горизонт 24 ч, дополнительные 72 ч | Контракт допускает 6 ч для исследований, диспетчерский прогноз минимум 24 ч |
| A03 | Локальная проверка допускает SQLite; целевое развёртывание PostgreSQL 15 | Docker CLI установлен, демон на момент начала недоступен; PostgreSQL-специфичные проверки отдельно |
| A04 | Условные сроки ТО конфигурируются | РТЭК не предоставлен, юридическое соответствие не сертифицируется |
| A05 | Внешние интеграции реализуются через конфигурируемые GET-адаптеры и файлы | Адреса и доступы заказчика отсутствуют, промышленная интеграция требует проверки |
| A06 | LDAP для целевого стенда; локальные демо-учётные записи только при AUTH_MODE=demo | Роли из доверенного каталога, пользователь не выбирает роль при входе |
| A07 | Команда, контакты и реальные показатели ML не выдумываются | Эти сведения участники добавляют перед сдачей |
| A08 | Прогноз ложности относится к конкретной последней сработке alarm_ref | Высокая вероятность ложности не означает высокий риск пожара или проникновения |
| A09 | Истина отделена от признаков; негативные метки только в покрытом наблюдениями периоде | Незавершённые горизонты исключаются из оценки |
| A10 | Шаблон ML явно stub; его обучение фиктивно и не является ML | Обучение выполняет другой участник |

Риски: редкие инциденты, синтетическое смещение, качество геокодирования, неизвестная схема источников, недоступность погоды, утечка будущего, ложные тревоги, недостаток истории и тестирование восстановления на промышленном объёме. Меры: раздельная истина, as_of-фильтры, fallback, дедупликация, обязательные решения человека, временная валидация, матрица испытаний.

Блокирующих вопросов для реализации нет. Перед промышленной эксплуатацией потребуются адреса источников/LDAP, РТЭК и реальные обезличенные данные.
