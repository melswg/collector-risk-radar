# Демонстрационный режим

### Настоящий расчёт модели

1. Запустите сервер и интерфейс, загрузите данные через `python -m backend.seed`.
2. Откройте `/` и войдите как `dispatcher`.
3. Откройте «Демонстрационные сценарии».
4. Нажмите «ML: новая тревога · синтетика».
5. Приложение создаст искусственный паспорт газового канала `990001` и события за текущий и предыдущие часы.
6. Откройте карточку. В ней должны быть источник ML, горизонт 24 часа, вероятность, канал и время расчёта.
7. Сохраните решение с причиной и комментарием. Оно появится в истории прогноза.

Прогноз получает статус «Порог не установлен». Для расчёта по искусственным данным используется модель `incident_24h.cbm`.

### Работа сотрудников

Карта, журнал событий и сохранённые решения доступны в рабочем месте диспетчера. У техника есть комментарии к работам, у руководителя общий обзор объектов.

Прогнозы по правилам обозначены меткой `rules`. Карта показывает условную сеть, камеры не передают видео. Telegram-доставка по умолчанию выключена; SMS и email сохраняются локально без отправки.
