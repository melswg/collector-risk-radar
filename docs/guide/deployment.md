# Docker и запуск стенда

README предлагает следующие команды:

```bash
make configure
make up
```

Для загрузки демонстрационных данных в спецификации предусмотрено:

```bash
make seed
```

Запуск на чистой машине ещё не проверен по текущему отчёту команды.

В спецификации описаны PostgreSQL, Redis, API, worker, scheduler и frontend с nginx. Дополнительно предусмотрены OpenLDAP, эмулятор источника и отдельный сервис по профилю `ml`.

Точные порты, образы и тома в использованных файлах Markdown не перечислены. Перед запуском на сервере нужно проверить миграции, сохранение данных после перезапуска, корпоративный вход, TLS и восстановление из резервной копии.

Для резервного копирования спецификация называет `make backup`. Восстановление за четыре часа, обработка до 300 секунд и работа 20 пользователей пока являются требованиями, а не подтверждёнными результатами.
