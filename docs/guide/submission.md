# Сдача проекта

Для сдачи нужны ссылки на репозиторий, документацию, презентацию и работающий прототип. Дополнительно можно приложить запись демонстрации и результаты проверок. Эксперты должны открывать материалы без прав участника команды.

Срок сдачи: **29 сентября 2026 года, 23:59 МСК**. После этого времени сданные материалы и стенд не меняются. Дальнейшая работа ведётся отдельно от сданной версии.

Этот файл описывает `develop`. Готовность релиза в `main`, адрес опубликованного стенда и ссылка на презентацию в использованных документах не подтверждены.

В требованиях к сдаче также указана документация в DOCX/PDF. Этот файл подготовлен в Markdown и может служить основой для этих форматов.
