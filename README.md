# Москоллектор 
## О проекте

«Москоллектор» помогает следить за состоянием инженерных коллекторов Москвы и не терять время, когда появляется опасный сигнал. Сервис собирает события мониторинга, показывает объекты на карте, оценивает риск на ближайшие 24 часа и сохраняет решения сотрудников. Он помогает людям разобраться в ситуации, но не управляет оборудованием сам.

У каждой роли свой рабочий путь. Диспетчер видит карту, сигналы и данные по выбранному объекту, проверяет ситуацию и фиксирует решение. Ремонтный работник получает сведения об участке, схему и рекомендации для выезда. Руководитель смотрит общую картину, приоритеты и ход работ. Для проверки качества прогнозов предусмотрено рабочее место аналитика.

В интерфейсе прогноз отделён от подтверждённого происшествия. Критический сигнал заметен сразу, но окончательное решение остаётся за человеком. История событий и действий помогает следующей смене понять, что уже произошло и что было сделано.

Сейчас доступен интерактивный прототип. Карта, расположение объектов, трассы и камеры в демонстрации условные; живой видеопоток не подключён. Прогнозы в веб-демо помечены по источнику, поэтому расчёт по правилам не выдаётся за результат подключённой ML-модели.
